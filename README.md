# 🔦 어둠 속의 메아리 (Echoes in the Dark)
> **Three.js 기반 1인칭 3D 심리 공포 탈출 웹 게임 (1st-Person 3D Horror Escape)**

외부 3D 에셋이나 오디오 파일 다운로드 없이, 브라우저 표준 기술(Three.js, Web Audio API, Canvas 2D 절차적 텍스처)만으로 구현된 완전 자립형 1인칭 3D 공포 탈출 게임입니다.

---

## 📖 시놉시스 (Synopsis)

정체불명의 폐쇄된 지하 시설물에서 깨어났습니다. 손에 쥐어진 손전등의 배터리는 빠르게 소모되어 가고, 어두운 복도 구석에서는 알 수 없는 기괴한 기운이 맴돕니다. 

벽면에 피로 새겨진 3개의 암호 단서를 찾아내고, 방전되기 전에 배터리를 보충하며 비상 탈출용 에어락 도어를 열고 탈출해야 합니다. 만약 손전등 불빛이 꺼진다면... 어둠 속에서 굶주린 원혼이 당신을 찾아올 것입니다.

## 🎮 조작 방법 (Controls)

| 키 / 입력 | 기능 | 설명 |
| :--- | :--- | :--- |
| **W, A, S, D** | **이동** | 전진, 후진, 좌측/우측 평행 이동 (벽 슬라이딩 충돌 판정 적용) |
| **Shift** | **전력 질주 (달리기)** | 이동 속도 대폭 증가 (45 → 75) 및 역동적 시야각(FOV) 확장 |
| **Spacebar** | **손전등 ON / OFF** | 손전등을 끄면 **배터리 소모가 중단**됩니다 (어둠 속 절약 전략) |
| **마우스 이동** | **시점 회전** | `PointerLockControls`를 통한 360도 1인칭 FPS 시야 조작 |
| **E** 또는 **마우스 좌클릭** | **상호작용** | 조준선(크로스헤어)으로 배터리 획득, 단서 확인, 탈출문 개방 |
| **ESC** | **마우스 락 해제** | 게임 일시정지 및 마우스 커서 반환 |

## 🕹️ 핵심 게임 메커니즘 (Core Gameplay Systems)

### 1. 손전등 & 배터리 서바이벌 (Battery Management)
- 손전등이 **ON** 상태일 때 배터리가 초당 약 **1.5%**씩 지속 소모됩니다.
- **Spacebar**로 손전등을 끄면 배터리 소모가 멈추며, 남은 전력을 아낄 수 있습니다.
- 배터리가 **20% 이하**로 떨어지면 불안정한 깜빡임(Flicker) 현상이 시작되며 경고음이 울립니다.
- 배터리가 **0%**가 되면 손전등이 완전히 소등되며 공포의 카운트다운이 시작됩니다.
- 복도 곳곳에 배치된 **노란색 배터리 팩(3개)**을 획득하면 배터리가 즉시 **+25%** 충전됩니다.

### 2. 귀신 출현 및 추격 AI (The Haunting Entity)
- **발동 조건**: 손전등 배터리가 0%가 되면, 등 뒤 먼 복도에서 섬뜩한 비명소리와 함께 원혼(귀신)이 소환됩니다.
- **외형**:
  - 피 묻은 하얀 소복과 어깨 위로 길게 늘어진 산발 머리카락
  - 어둠 속에서 번뜩이는 핏빛 안광(Point Light 연동)
  - 관절이 뒤틀린 팔과 뾰족한 손가락, 기괴하게 떨리는 척추 애니메이션
- **추격 로직**:
  - 초당 3.3m 속도로 플레이어를 향해 장애물을 통과하며 직진 추격합니다.
  - 플레이어와의 거리가 1.3m 이내로 좁혀지면 **강렬한 점프스케어(비명 + 붉은 노이즈 왜곡)와 함께 게임 오버**됩니다.
  - 귀신이 나타난 상태에서도 복도의 배터리를 찾아 주워 전력을 복구하면, 불빛의 정화 작용으로 귀신이 즉시 소멸합니다.

### 3. 암호 해독 & 탈출 루프 (Escape Loop)
- **비밀 단서**: 미로 같은 복도 벽면에 붉은 형광빛으로 새겨진 3개의 숫자 단서(`4`, `7`, `2`)가 숨겨져 있습니다.
- **상호작용 판정**: 3.5m 이내에서 조준선으로 조준 후 `E` 키 또는 클릭 시 단서를 해독하여 상단 HUD에 기록됩니다.
- **에어락 탈출구**: 3개의 단서를 모두 해독한 상태로 복도 끝의 대형 방폭문에 접근해 상호작용하면 탈출에 성공(Clear)합니다.

## 🛠️ 기술적 특징 & 아키텍처 (Technical Architecture)

외부 CDN 리소스 실패나 네트워크 단절 상황에서도 100% 정상 작동하도록 모든 그래픽과 사운드를 브라우저 API로 순수 연산 생성합니다.

### 1. 절차적 텍스처 생성 (Procedural Canvas Textures)
- `createNoiseTexture()`: HTML5 Canvas 2D 컨텍스트에서 픽셀 단위 펄린 노이즈를 연산하여 콘크리트 바닥과 천장의 거친 질감 표현.
- `createWallTexture()`: 폐쇄 시설의 산업용 금속 패널 그리드, 리벳 볼트 라인, 녹슨 그라데이션 절차적 렌더링.
- `createClueTexture()`: 피가 번진 듯한 그러데이션과 불길한 룬/숫자 발광 텍스처.
- `createDoorTexture()`: 경고 사선 스트라이프 및 LED 상태 표시등이 달린 방폭문 텍스처.

### 2. Web Audio API 기반 신디사이저 (Pure Procedural Audio)
별도의 사운드 파일(mp3, wav) 없이, Web Audio Context의 오실레이터와 노이즈 버퍼를 조합하여 실시간 오디오를 합성합니다.
- **발걸음 소리 (Footsteps)**: 저주파 핑(BiquadFilter)과 감쇠 엔벨로프를 조합해 걷기/달리기 주기에 맞춰 재생.
- **스위치 찰칵음 (Flashlight Toggle)**: 고주파 펄스 클릭 사운드.
- **배터리 충전음 (Item Pickup)**: 상승하는 2화음 신스 톤.
- **단서 해독음 (Clue Found)**: 오싹한 감쇠 메이저/마이너 화음.
- **귀신 비명 (Ghost Scream)**: 삼각파/톱니파 주파수 스윕(FM 합성)을 통한 전율적인 절규음.
- **점프스케어 충격음 (Jumpscare Sting)**: 왜곡된 저주파 브라운 노이즈와 불협화음의 순간 타격.
- **문 개방음 (Door Open)**: 중후한 기계식 래치 및 공압 릴리즈 사운드.

### 3. 물리 및 렌더링 최적화
- **AABB 벽 충돌 & 슬라이딩**: 플레이어 바운딩 반경(0.65m)을 기준으로 X축, Z축을 독립 검증하여, 벽에 비스듬히 부딪혔을 때 부드럽게 미끄러지며 전진하는 FPS 이동 메커니즘.
- **조명 구성**:
  - `SpotLight` (플레이어 시점 연동 손전등, 감쇠율 및 반치각 정밀 설정)
  - `AmbientLight` & `HemisphereLight` (복도가 지나치게 칠흑 같지 않도록 음영부 가시성 보장)
  - `FogExp2` (깊이감과 공포감을 극대화하는 지수 안개)
- **반응형 렌더러**: 윈도우 리사이즈 이벤트 자동 감지 및 카메라 가로세로비(`aspect`) 자동 재계산.

## 🚀 실행 방법 (How to Run)

### 방법 1. 단일 HTML 파일로 즉시 실행 (Zero Dependency)
1. 루트 디렉터리의 `horror-escape.html` 파일을 Chrome, Edge, Whale, Firefox 등 모던 웹 브라우저로 더블 클릭하여 엽니다.
2. 화면 중앙의 **[탐색 시작]** 버튼을 클릭하면 전체 화면으로 마우스 커서가 고정되며 즉시 게임이 시작됩니다.

### 방법 2. Vite 개발 서버로 실행
```bash
# 1. 의존성 패키지 설치
npm install

# 2. 로컬 개발 서버 구동 (기본 포트: 3000)
npm run dev

# 3. 브라우저에서 접속
http://localhost:3000
```

### 방법 3. 프로덕션 빌드
```bash
npm run build
```

## 💡 게임 공략 팁 (Survival Tips)

1. **배터리 절약**: 이미 밝은 구역을 지나거나 벽을 더듬어 이동할 때는 `Spacebar`를 눌러 손전등을 꺼두세요.
2. **달리기 활용**: `Shift` 키를 누르면 빠르게 달릴 수 있으나, 배터리 소모는 손전등 켜짐 여부에만 따르므로 신속하게 단서를 확인하는 것이 유리합니다.
3. **귀신 대처**: 불이 꺼지고 귀신 비명이 들리면 당황하지 말고 기억해 둔 노란색 배터리 위치로 질주하세요. 배터리를 획득하는 즉시 손전등이 다시 켜지며 귀신이 퇴치됩니다.
4. **탈출문 위치**: 복도 가장 안쪽 끝에 거대한 붉은색 에어락 문이 위치하고 있습니다. 3개의 단서를 모두 모으면 문 중앙의 패널이 녹색으로 활성화됩니다.
